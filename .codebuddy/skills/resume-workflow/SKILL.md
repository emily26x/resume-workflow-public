# 简历事实与导出

先读取仓库根目录的 `CODEBUDDY.md`、`AGENTS.md` 和 `使用说明/workflow.md`，再完整读取 `.agents/skills/resume-workflow/SKILL.md` 并按其执行。本人资料不存在时按入口规则读取公开索引模板，不得把 `示例资料/` 的虚构事实用于真实简历。用户要求打开编辑器时，必须先启动本地编辑器并交付 HTTP 地址；静态 `resume.html` 不能代替带左侧调节面板的编辑器。
