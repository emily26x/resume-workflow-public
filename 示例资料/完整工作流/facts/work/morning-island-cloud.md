# 虚构示例乙云服务

- 任职时间：2023.07–2023.12
- 真实职位：用户运营
- 任职性质：实习

### morning-onboarding

- status: confirmed
- statement_id: morning-onboarding
- 背景：新注册团队对产品配置流程不熟悉，首次启用耗时较长。
- 行动：整理 86 条访谈与工单记录，重构入门任务清单，并联合客户成功团队组织 5 场线上训练营。
- 结果：训练营用户的核心功能启用率由 52% 提升至 71%。
- 能力信号：用户研究、内容设计、活动执行。

### morning-community

- status: confirmed
- statement_id: morning-community
- 背景：用户社群问题重复且响应标准不一致。
- 行动：建立问题分类、标准回复和升级机制，每周汇总高频问题并反馈产品团队。
- 结果：常见问题平均首次响应时间由 28 分钟缩短至 12 分钟。
- 能力信号：社群运营、服务流程、跨团队反馈。

### morning-data-review

- status: confirmed
- statement_id: morning-data-review
- 事实：使用 Excel 和 SQL 汇总注册、启用与留存数据，制作周度漏斗看板。
- 产出：连续 16 周更新数据，并记录口径、异常原因和行动建议。
- 能力信号：数据分析、指标管理、运营复盘。
