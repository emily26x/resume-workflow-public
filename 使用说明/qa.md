# 发布验收

## 自动检查

- Markdown 结构、状态和未确认内容检查。
- 三套模板渲染及内容 ID 稳定性。
- 模板切换保留编辑内容和每套排版参数。
- 默认模板缺失时回退到经典黑白。
- 默认内容偏好为无照片、隐藏城市和可读链接名称；显式设置可以恢复。
- 正文字号最低为 8.8 pt；95%～96% 只作为建议区间。
- 溢出、裁切和跨页时阻止导出；PDF 为一页且文字完整；PNG 为 2480 × 3508。
- 四个 Skill 的名称、触发描述、输出边界及 Codex/Claude Code 镜像一致性。
- 私人路径、私人公司规则和固定条数规则扫描。
- OpenCode 对 `AGENTS.md` 和 `.agents/skills` 的实际发现检查。

| Windows 11 | 待执行 | 待执行 | 待执行 | 尚未在真实设备验证 |

每个平台使用短、中、长三份虚构简历，覆盖有无照片、长姓名、链接、可选章节和双栏阅读顺序。记录模板切换耗时，正常简历目标为 1 秒内完成预览与检查。

当前 Mac 上，中等长度简历从经典黑白切换到灰白双栏并完成检查实测为 22 ms。自动测试 16 项全部通过，`npm audit` 为 0 个漏洞。完整端到端测试包含浏览器启动，因此总测试时间不等于模板切换时间。

OpenCode 1.4.6 的 `debug config` 已实际发现 `resume-workflow`、`resume-tailor`、`job-greeting` 和 `interview-introduction`。不写文件的模型触发测试已发起，但当前 OpenCode 账户返回余额不足，因此没有获得模型回答；该限制不影响本地规则和 Skill 发现结果。
