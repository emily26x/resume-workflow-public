# 开发维护

程序与维护文件集中在“开发”，用户资料在根目录中文文件夹。模块内部相对引用保持不变，配置和资料路径以仓库根目录为基准。

所有命令在项目根目录执行：

```bash
npm test
npm run test:opencode
npm run privacy-check
npm run previews
```

模板预览使用“示例资料/排版案例/resume-medium.md”，预览图写到“使用说明/images”。浏览器测试依赖可用 Chrome、Edge 或 Chromium。

## 目录迁移对照

| 原位置 | 新位置 |
|---|---|
| raw | 原始材料 |
| resume/facts | 示例资料/完整工作流/facts（旧虚构事实）；本人事实使用简历事实库 |
| resume/applications | 示例资料/完整工作流/applications（历史演示） |
| examples | 示例资料/排版案例 |
| docs | 使用说明 |
| src、editor、templates、scripts、tests、evals | 开发下对应同名目录 |

新增本人事实推荐使用 `个人资料.md`、`教育背景.md`、`个人技能.md`、`工作经历/`、`项目经历/` 和 `荣誉奖项.md`；索引由 AI 按实际内容维护。内部事实 ID 保持稳定。

## 当前验证范围

支持中文单页 A4、本地编辑与导出。macOS 已验证；Windows 路径按跨平台方式实现，但仍需在真实 Windows 环境执行发布验收。OpenCode 技能发现检查与模型实际回答是两项不同验证。

`npm run privacy-check` 分别读取 Git 已跟踪文件和暂存区快照，检查私有目录误提交、常见个人信息、绝对路径和常见密钥。未知二进制文件默认阻断；公开图片需人工复核内容与元数据，再把文件路径和 SHA-256 写入检查器白名单。检查器用于拦截普通误操作与 `git add -f`，不能替代发布前人工复查。
