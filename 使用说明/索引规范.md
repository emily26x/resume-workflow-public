# 索引写法与维护规则

_index.md 展示当前资料与导航，README 解释操作方法。索引摘要不能代替事实正文核验。

## 元数据

```yaml
---
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags:
  - type/index
  - status/final
aliases: []
---
```

created 取索引首次创建当天的本地日期，后续不变；迁移已有索引时沿用可核实的原创建日期。updated 取最近实际修改日期。type/index 标识目录索引；status/final 只表示索引已整理完成，不代表其中的事实已确认或简历已定稿。别名按需填写，没有则保留 []。

## 正文

1. 清楚命名标题，例如“简历事实库 - 索引”。
2. 用一小段说明目录用途、内容范围与使用边界。
3. 分类列表或表格展示内容，每个入口附具体用途或一句话摘要。
4. Related 使用标准 Markdown 相对链接，关联上层索引、相关目录或指南，并说明关系。
5. 有实际来源需要追溯时添加 Source，不机械填写。

## 导航字段

| 目录 | 字段或组织方式 |
|---|---|
| 事实库总索引 | 分类、入口与内容说明；有资料时展示实际资料 |
| 工作经历 | 经历、时间、任职性质、核心内容、核实状态 |
| 项目经历 | 项目、时间、项目性质、核心内容、核实状态 |
| 岗位档案总索引 | 年份、该年份档案范围或用途、年度索引入口；按年份倒序 |
| 年度岗位档案 | 生成日期、公司、岗位、文案状态与文件入口；按日期倒序 |
| 示例资料 | 案例、演示用途、包含内容；明确为虚构资料 |

新正式档案创建后维护 `岗位档案/YYYY/_index.md`，年度索引指向具体 resume.md，岗位档案总索引只按年份导航。HTML、PDF 和 PNG 实际生成后才增加相应链接。已有历史演示保留原目录，不为整理索引迁移或猜填日期。

## 维护

- 新建或更新资料时，同步受影响的各层索引及 updated；created 不变。
- 只链接真实存在的文件或子索引，不为预期内容创建空链接。
- 上层概览，下层展开，不重复列出所有底层文件。
- 空目录写清下一步操作，不填写虚构条目或伪装成真实文件的占位链接。
- 状态、时间和性质以正文为依据；缺少记录时注明未记录，不推断。
- 内容为空时保留说明即可，不创建没有用途的年度或经历子目录。
